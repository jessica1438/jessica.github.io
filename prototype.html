AI Engineer, Solutions and Data Engineer

I build AI agent solutions for enterprise data teams — from automated data cataloging and metadata enrichment across cloud warehouses, to RAG-based chatbots that help financial analysts get answers faster, to deep learning pipelines for KYC document verification using computer vision models. My work sits at the intersection of AI and data infrastructure, turning complex governance and automation challenges into production-ready solutions using tools like Claude API, MCP integrations, Snowflake, and AWS.

Outside of work, I'm building StrideAI — a fullstack AI-powered running coach built with React, Tailwind, Next.js, Convex, Clerk, and Claude API, deployed on Vercel. I hold an MS in Data Analytics Engineering from Northeastern University and a BTech from VIT. I'm passionate about shipping AI solutions that solve real problems — whether that's enterprise data governance or helping someone run their first 5K.
